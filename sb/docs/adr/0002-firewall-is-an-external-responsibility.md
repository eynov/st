# ADR 0002：防火墙是外部责任

- 状态：Accepted
- 日期：2026-07-25

## 决策

sb 不自动修改 nftables、iptables、fwctl、云安全组或控制面板防火墙。项目只生成
协议、端口和转发需求，并提供可复制的 nftables/iptables 示例。

## 原因

通用 VPS 的网络控制面不同，自动写规则会造成所有权冲突和不可预测的远程锁死风险。
保持边界后，sb 可以独立验证配置，用户则按自身平台管理网络入口。

## 后果

HY2 Port Hopping 必须同时提示完整 UDP 范围放行及 range→base 转发；“已放行”不能
表述为“已完成转发”。doctor 只能提示外部责任，不能声称已验证云侧可达性。
